# Live Swing Playbook & Anti-Patterns

## Validated High-Probability Edge
- *Pullback to 20 EMA after high-volume earnings gap*: Win rate is highest when RSI holds above 50 during consolidation.

## Confirmed Negative Edge (Avoid / Hard Invalidation)
- *Breakout above resistance during Fed announcement week*: High false breakout rate. Disqualify setup regardless of volume.
- *Small-cap biotech / FDA news runups*: Sentiment agent frequently over-weights PR fluff. Ignore these tickers.
